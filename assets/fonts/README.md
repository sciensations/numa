# Bundled fonts

Atkinson Hyperlegible Next Regular and Bold are vendored from
[`googlefonts/atkinson-hyperlegible-next`](https://github.com/googlefonts/atkinson-hyperlegible-next)
at commit `7925f50f649b3813257faf2f4c0b381011f434f1`.

The `.ttf` files are used for Typst print output and the `.woff2` files are
self-hosted by the generated website. The font is distributed under the SIL
Open Font License 1.1 in `OFL.txt`.

`Noto-COLRv1-noflags.ttf` is Noto Color Emoji from
[`googlefonts/noto-emoji`](https://github.com/googlefonts/noto-emoji/tree/v2.051),
pinned to release `v2.051`. Its SHA-256 is
`469e3b92d63cfc203789f8742f1835b8672c7b5995ab4a832f1699b712a5afcc`.
Card difficulty stars select this font explicitly so `emoji.star` prints in
color even with system fonts disabled. Its SIL Open Font License is in
`NotoEmoji-OFL.txt`.
